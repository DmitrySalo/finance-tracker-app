# React Frontend

Read `.opencode/instructions/frontend-style.md` and follow existing UI, styling, routing, API-client, and test conventions. Preserve responsive behavior and use semantic HTML, keyboard support, visible focus, and complete loading, empty, error, and success states.

Keep server state separate from local UI state. Prefer precise TypeScript types and composition; avoid `any`, unnecessary effects, and speculative memoization. Do not add a UI, state, form, or fetching library unless the existing solution cannot meet the requirement.
