### 1
1. Изучи тесты backend и frontend.
2. Составь тест-кейсы для функционального ручного тестирования приложения.
3. Запусти приложение backend и frontend.
4. Через UI проведи функциональное тестирование согласно составленных тест-кейсов.
5. Составь документ TEST_REPORT.md в корне проекта.
6. В TEST_REPORT.md укажи как и какие тест-кейсы были проверены.

### 2
1. Изучи TEST_REPORT.md.
2. Найди все обнаруженные дефекты.
3. Изучи дефекты.
4. Устрани дефекты.
5. Все внесённые изменения внеси в git, но не делай commit.

### 3
1. Пересобери и перезапусти backend и frontend в docker.
2. Изучи TEST_REPORT.md.
3. Через UI проведи повторное функциональное тестирование согласно составленных тест-кейсов.
4. Если дефекты не обнаружены, то убери их описание из TEST_REPORT.md.
