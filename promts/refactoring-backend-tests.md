1. Изучи структуру тестов backend/src/test.
2. Обрати внимание, что в интеграционных тестах часто заново создаются и запускаются spring context и контейнер с postgres.
3. Отредактируй интеграционные тесты java так чтобы spring context создавался только один раз, если это возможно по условиям тестовых сценариев.
4. По необходимости добавь функционал очистки контекста перед запуском тестов там, где это необходимо.
5. Отредактируй интеграционные тесты java так чтобы контейнер с postgres создавался и запускался только один раз, если это возможно по условиям тестовых сценариев.
6. Добавь функционал очистки базы данных postgres запущенной в контейнере перед запуском тестов там.
7. Добавь над тестами аннотацию @DisplayName в параметре которой нужно добавить описание проверяемого кейса. Описание кейсов должно быть на русском на русском языке.
8. Новые требования к тестам зафиксируй в файле .opencode/instructions/testing.md.
