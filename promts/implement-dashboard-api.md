# Реализовать dashboard API

Работай только над шагом 16 плана разработки из ARCHITECTURE.md: реализуй dashboard API с ограниченными агрегирующими запросами (pie расходов по категориям за месяц, line trend за шесть месяцев, top-5 категорий). Это отдельная подзадача, завершить ее полностью. Соблюдай AGENTS.md: сначала прочитай ARCHITECTURE.md, .opencode/instructions/architecture.md, java-style.md и обязательные по задаче database.md, api-contracts.md, testing.md, security.md, а также локальные AGENTS. Прочитай существующий код и соглашения. Реализуй минимально, добавь релевантные integration tests. Запусти ./gradlew verify. После успешных проверок выполни обязательный code review доступным способом, устрани критичные замечания. Затем создай promts/<имя-коммита>.md с исходным заданием шага, добавь корректную следующую запись в REPORT.md, проверь git status/diff/log, и создай один коммит в ветке develop, включив только файлы этого шага. Не трогай чужие изменения. Верни: краткое описание, тестовые команды/результат, hash коммита и список измененных файлов.
